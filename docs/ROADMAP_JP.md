# TransitionFX ロードマップ

> 今後のリリースで予定している機能です。コミュニティのフィードバックに応じて優先度は変更される場合があります。機能要望は [GitHub Issues](https://github.com/EmbarrassingMoment/TransitionFX_Dev/issues/new/choose) で受け付けています。

---

## 予定

### 新エフェクト
- [ ] 新しいトランジションエフェクトを追加予定 — 具体的なエフェクトはユーザーフィードバックやクリエイティブな検討を踏まえて決定

### 機能拡張
- [ ] **残りのエフェクトのウィジェットレイヤー版** `High` — v1.5.0 で提供した 8 エフェクト以外にも `WidgetTransitionEffect` 対応を広げる。Pixelate と Slice はマテリアルの構造上ウィジェットレイヤーで再現できないため対象外
- [ ] **原点オーバーライド** `Medium` — Iris、Diamond、Tiles などの中心ベースのトランジションを、任意のスクリーン座標から展開できるようにする
- [ ] **複数トランジションの同時再生** `Low` — マルチスロットマネージャーによる複数の独立したトランジションのレイヤリングをサポート

### 改善・最適化
- [ ] **エディタでのプリセットバリデーション** `High` — マテリアル未設定や必須パラメータ `Progress` の欠落を警告する
- [ ] **エディタプリセットサムネイル** `Medium` — コンテンツブラウザで TransitionPreset アセットの静的サムネイルを自動生成し、一目で識別しやすくする
- [ ] **ブループリントプリセットピッカーウィジェット** `Medium` — ミニプレビュー付きのビジュアルドロップダウンで利用可能なプリセットを表示
- [ ] **シェーダー複雑度ティア** `Low` — パフォーマンスに敏感なプラットフォーム向けの簡略化されたマテリアルバリアント

### ドキュメント・チュートリアル
- [ ] **マテリアルパラメータリファレンス** `High` — 全ビルトインマテリアルの調整可能なパラメータを一覧にした専用ドキュメント
- [ ] **動画チュートリアル: はじめに** `Medium` — インストール、プリセット作成、最初のトランジション再生のウォークスルー
- [ ] **動画チュートリアル: レベル遷移ワークフロー** `Medium` — `OpenLevelWithTransition` と HoldAtMax ローディング画面パターンのデモ
- [ ] **カスタムエフェクト作成ガイド** `Medium` — 新しい SDF マテリアルの作成と `ITransitionEffect` での組み込みのステップバイステップガイド
- [ ] **一般的なパターンのブループリント例** `Medium` — 一般的なパターン（ポーズメニュー、レベルセレクト、カットシーン遷移）の設定済みブループリント例

## 提供済み

| 項目 | リリース |
| :--- | :--- |
| **UMG ウィジェットレイヤートランジション** — UMG/Slate UI ごと覆えるフルスクリーン Slate オーバーレイの描画経路（`WidgetTransitionEffect`）。8 エフェクトで提供 | v1.5.0 |
| **プールサイズの設定** — エフェクトプールの上限を **プロジェクト設定 > プラグイン > TransitionFX** の `MaxPoolSizePerEffectClass` で公開 | v1.4.0 |
| **プリセットごとのトランジションカラー** — プリセットの `bOverrideTransitionColor` / `TransitionColor` で、呼び出し側のオーバーライドなしにフェード先の色（白など）を指定 | v1.3.0 |
| **トランジションチェイン / シーケンス** — DataAsset ベースでプリセットを連続再生し、任意でループも可能 | v1.2.0 |
| **OnTransitionProgress デリゲート** — `OnTransitionProgressChanged` による毎ティックの進捗通知と、`AddProgressThreshold` による閾値コールバック | v1.1.0 |
| **サンプルプロジェクト** — `L_ShowCase` と `L_WidgetLayerSample` レベルを含むサンプルプロジェクト | [Releases ページ](https://github.com/EmbarrassingMoment/TransitionFX_Dev/releases) |

リリース履歴の詳細は [CHANGELOG.md](../CHANGELOG.md)（英語）を参照してください。
